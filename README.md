# Hi, I'm Ramtin 👋

🎓 **MSc in Data Science** — University of Padua  
⚛️ **BSc in Physics** — Sharif University of Technology  
📍 Based in Padova, Italy

I'm interested in natural language processing, computer vision, and computational social science. My work includes transformer-based text summarization, evaluating language models, medical image classification, and modelling social interactions.

## 🔬 Selected projects

- **Text summarization — Master's thesis:** Developed unsupervised extractive summarization methods using a pretrained hierarchical transformer, combining sentence relevance scores with redundancy control.
- **LLM reasoning:** Evaluated Llama-2-13B on 480 ConceptARC tasks, analysing task accuracy and output dimensions alongside published human and GPT-4 results.
- **Medical imaging:** Built an attention-guided CNN for multi-label chest X-ray classification, combining full-image features with features from local regions.
- **Social network analysis:** Analysed sentiment, engagement, and community structure in a dataset of over 460,000 Reddit posts about the Israel–Palestine conflict.

## 📝 Research

Co-author of **“A Computational Approach to Homans’ Social Exchange Theory”** (*Physica A*, 2022), using agent-based modelling to study social interactions and group formation.

## 🛠️ Tools

**Languages:** Python · R · SQL  
**Machine learning:** PyTorch · TensorFlow · scikit-learn  
**Data analysis:** pandas · NumPy  
**Development:** Git · Linux · Jupyter
